# Retired: Switchboard connector

This plugin has been replaced by built-in bidirectional **Peers** in [Switchboard](https://github.com/tader/switchboard).

Add an incoming peer on one instance, then an outgoing peer on the other using its URL and device token. Both sides choose local connections to share in **Connections → Sharing**. No connection is shared automatically. See [the peer guide](https://github.com/tader/switchboard/blob/main/docs/guides/peers.md).

Existing plugin connection records and credentials remain stored, but the retired plugin cannot be enabled on current Switchboard. Configure peers explicitly instead. This repository is archived and receives no further releases.
